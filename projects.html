P-01

Inventory & Demand Forecasting System

  • FastAPI
  • PostgreSQL
  • Redis
  • Docker

What it does

Tracks inventory and stock alongside suppliers, purchase orders, warehouse operations and reporting. It forecasts demand from past sales to flag likely stock shortages and suggest restocking.

Engineering

  • PostgreSQL schema and query tuning for fast reporting
  • Redis caching for frequently read data
  • Asynchronous processing for heavy jobs
  • Containerised with Docker

Job Portal & Recruitment Management System

  • FastAPI
  • PostgreSQL
  • Redis
  • Docker
  • NLP

What it does

A full-stack recruitment platform covering job posts, applications, résumé uploads, interview scheduling and application tracking. It matches candidates to jobs automatically using AI semantic analysis.

Engineering

  • Role-based access control, advanced search and filtering

P-03

Greeny: Grocery E-Commerce Platform

  • Django
  • PostgreSQL
  • REST APIs

What it does

A grocery store with a product catalogue, categories and brands, user accounts, cart, checkout, secure payments and order tracking. It offers AI product recommendations based on each customer's preferences and shopping history.

Features

  • AI-powered product recommendations
  • Product comparison and order history
  • Profile management and a content / blog section
  • REST APIs for the full shopping flow
